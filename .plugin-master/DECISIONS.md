# Decisions

## 2026-10-17 Navigator
1. **Standalone agent, evaluated against bare only.** Why: the old insertion broke routes (a confident map skipped it and fenced the model; always-on doubled investigate cost). Rejected: route insertion / calls from investigate and plan.
2. **Feature-oriented map in `.ambicode/navigator/features.md`, separate from `context/`.** Entry: feature, terms, files, deps, models. Why: a prompt often does not name its feature, so term-to-path lookups miss it. Budget 2500 tokens (chars/4), at most 30 entries of 80 tokens (user set 2026-10-17, was 2000). Rejected: per-module `## Keywords` (0 recall gain twice), flat term-to-path list.
3. **Learning (step 4) kept and tested.** Why: the user's case ("fix modal for location for user migration") shows grep cannot find unnamed features. Rejected: ship without step 4.
4. **Fixtures derived from the 20 real NDA nav cases stay local** (outside committed files). Rejected: committing them.
5. **`harvest` ecosystem patterns (`DECLARATION_PATTERNS`) deferred.** Why: no failure observed. Revisit only if it fails.
6. **Navigator eval runs one case at a time with map copy-back.** Why: a symlink to the persistent map was EPERM in the sandbox. Rejected: symlinked map.
7. **Navigator results merged into `results/<arm>.json`; navigator excluded from the default suite run (`--tag navigator` only).** Why: it is costly and has its own bench.
8. **Map = directory index (hierarchy + flat by file count) + learned entries in one 2500-token budget.** Index <=900 tokens generated by `navigator seed`, `# Learned` entries (max 20) written only by `navigator learn`, which never touches the Index and evicts the oldest learned entries. Why: the cap-driven seed folded directories under 46 files and hid sibling/feature dirs (bench: 1779 files, niosh/rsi/lm-* gone, names only last segment). Rejected: one entry per feature dir (~3400 tokens, needs depth detection), bigger budget.
